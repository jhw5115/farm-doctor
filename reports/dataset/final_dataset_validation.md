## 코드 매핑

`config/dataset_mapping.yaml`의 고정 ID 0~8은 유지했습니다. `config/official_disease_codebook.csv`는 제공된 AI Hub 데이터셋 146 / v1.0 표로 갱신했고, 이전 파일은 `config/official_disease_codebook.pre_aihub_2026-10-16.csv`에 보관했습니다. 자세한 상태와 9개 대조표는 [codebook_verification.md](./codebook_verification.md)를 참조하세요.

## 의도적 학습용 서브셋 구성 및 영향

| 이전 manifest 폴더 | 이전 이미지/JSON | 현재 이미지/JSON | 현재에 없는 쌍 |
|---|---:|---:|---:|
| 배 정상 | 500 / 500 | 100 / 100 | 400 |
| 배 질병 | 500 / 500 | 500 / 500 | 0 |
| 사과 정상 | 500 / 500 | 100 / 100 | 400 |
| 사과 질병 | 500 / 500 | 500 / 500 | 0 |
| **합계** | **2,000 / 2,000** | **1,200 / 1,200** | **800** |

현재에 없는 800개는 누락 또는 손상이 아니라, 학습 시간을 줄이기 위해 사용자가 의도적으로 제외한 정상 클래스의 학습용 다운샘플링입니다. 원본 2,000개는 기준 데이터로 유지하며, 이전 CSV 경로와 현재 학습용 서브셋의 대조 결과는 [excluded_images.csv](./excluded_images.csv)에 있습니다. 향후 원본 800개를 다시 포함하는 전체 데이터 실험을 수행하면 학습/평가 분포와 split이 달라지므로, 코드북·누수 검사를 다시 수행한 뒤 **별도 모델로 재학습·재평가**해야 합니다. 이는 현재 1,200개 서브셋이 잘못되었거나 반드시 복구되어야 한다는 뜻은 아닙니다.

## 현재 분할과 정상 클래스 평가 한계

| 클래스 | 전체 | Train | Val | Test |
|---|---:|---:|---:|---:|
| pear_healthy | 100 | 64 | 25 | 11 |
| pear_scab | 250 | 175 | 50 | 25 |
| pear_fire_blight | 250 | 175 | 50 | 25 |
| apple_healthy | 100 | 70 | 20 | 10 |
| apple_brown_spot | 100 | 62 | 22 | 16 |
| apple_fire_blight | 100 | 66 | 20 | 14 |
| apple_valsa_canker | 100 | 51 | 37 | 12 |
| apple_alternaria_leaf_spot | 100 | 70 | 20 | 10 |
| apple_anthracnose | 100 | 64 | 20 | 16 |
| **전체** | **1,200** | **797** | **264** | **139** |

정상 두 클래스는 각각 100개이며 테스트 표본도 배 11개, 사과 10개뿐입니다. 배 질병 클래스 두 개는 각각 250개이므로 현재 클래스 최대/최소 비율은 2.5:1입니다. 이는 실험 학습을 막는 수준은 아니지만, 정상 클래스의 다양성 및 지표의 신뢰구간을 제한합니다. 그룹 단위 분할 결과 전체 비율은 66.4% / 22.0% / 11.6%이며 설정값 70% / 20% / 10%와 다릅니다.

## 학습 후 정상 클래스 오진율 검증 계획

1. 고정된 현재 Test split에서 `pear_healthy`와 `apple_healthy` 각각의 recall, precision, F1 및 혼동행렬을 별도로 보고합니다.
2. 정상 이미지를 질병으로 예측한 건수를 정상 클래스별 false-positive 진단 건수와 오진율(`정상을 질병으로 예측 / 정상 Test 수`)로 기록합니다. 분모는 각각 11개와 10개임을 함께 명시합니다.
3. 정상으로 예측한 질병 이미지의 false-negative 진단 건수도 질병 클래스별로 기록합니다.
4. 작은 정상 Test 수로 인한 불확실성을 보고하고, 가능하면 학습에 사용하지 않은 추가 정상 이미지로 외부 평가를 수행합니다. 외부 평가는 현재 실험용 1,200개 서브셋의 READY 판정을 바꾸지 않지만, 운영 적용 판단에는 필요합니다.

## 재실행 검사 결과

- 이미지·JSON: 현재 입력 1,200개씩 모두 매칭되었고, 변환 산출물에도 1,200개씩 반영되었습니다.
- 누수: SHA-256 동일 이미지 17개 그룹(34개), perceptual-hash 후보 14쌍, 파일명 촬영 prefix 205개 그룹은 모두 단일 split 안에 있었습니다. 실제 개체/나무/세션 ID가 없어 개체 단위 누수는 검증 불가입니다.
- Classification: 9개 클래스, 생성 이미지 손상 0건, ZIP CRC 1,203개 항목 통과(기존 산출물 검사).
- Detection: 이미지/TXT 각 1,200개, 누락/빈 라벨/비정상 bbox 0건, ZIP CRC 2,403개 항목 통과(기존 산출물 검사). bbox는 병변이 아닌 주목 객체입니다.
- pytest: 변환기 전용 테스트는 `17 passed`입니다. 전체 pytest는 기존 백엔드 `app` import 경로 및 처리 디렉터리/기본 pytest 임시경로 권한 문제로 수집 단계에서 중단되어, 전체 프로젝트 통과로 해석하지 않습니다.

분류 또는 주목 객체 탐지를 진행한다면 위의 조건부 판정을 실험 기록에 남기고, 정상 클래스별 소수 테스트셋 지표의 신뢰구간/오류 사례를 함께 보고하세요.
