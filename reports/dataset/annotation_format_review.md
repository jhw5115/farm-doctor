# 어노테이션 포맷 대조 결과

- 입력 JSON: 1,200; 이미지-JSON 매칭: 1,200.
- JSON 파싱 오류: 0건; 필수 annotation 구조/code 오류: 0건; bbox/이미지 크기 문제: 0건.
- `description.type`: null은 허용 처리했습니다. 실제 분포는 분석 보고서의 description.type 항목을 참고하세요.
- `annotations.area`: 제공 포맷의 값 범위 0~7; 실제 분포 1=228, 2=4, 3=625, 4=143, 5=68, 8=10, 9=108, 10=7, 11=7.
- 범위 초과 area: 8=10, 9=108, 10=7, 11=7. 이 필드는 학습 클래스 판정에 쓰지 않고 원본 값을 metadata.csv에 보존합니다.
- `annotations.grow`: 제공된 표에는 11, 12, 13이 제시됐으나 실제 관측은 21=100, 22=388, 23=512, 25=186, 26=14입니다. 코드 체계/버전 차이 여부는 제공처 확인이 필요하며 값을 임의 변환하지 않고 metadata.csv에 보존합니다.
- `crop`, `disease`, `risk` 실제 코드는 설정된 범위 및 승인된 로컬 crop+disease 매핑으로 검사했습니다.
- `points`는 제공된 정의대로 주목 객체의 bbox입니다. Detection 라벨은 주목 객체 위치를 뜻하며 병변 위치를 뜻하지 않습니다.
- Detection 좌표는 실제 이미지 크기 기준으로 검사했으며 범위 밖 좌표를 자동 보정하지 않았습니다.
